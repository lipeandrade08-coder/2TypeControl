# 2Type Control — Asset Pack

Pacote vetorial e PNG preparado para implementação no front-end.

## Pastas
- `logos/svg`: logotipos vetoriais.
- `logos/png`: versões PNG transparentes.
- `symbols`: símbolo isolado em cor, branco e preto.
- `app-icons`: app icon, favicon e tamanhos comuns.
- `interface-icons/svg`: ícones de navegação com `stroke="currentColor"` para estilizar via CSS.
- `interface-icons/png`: exportações 256×256 para uso não-vetorial.
- `design-tokens`: variáveis CSS da identidade.

## Uso recomendado
No front-end, priorize SVG. Os ícones de interface aceitam `color` via CSS porque usam `currentColor`.
